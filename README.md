# packagefinder
packagefinder is a new software search tool created by djemos (Dimitris Tzemos) for Slackel, Salix, and Slackware.
It provides a unified search environment across all versions and central or third-party repositories. 

# Key Features
# Universal Ecosystem Support:
Works across all versions of Slackel, Salix, and Slackware. 
# Combined Search: Queries official and external third-party repositories in one place.
# Technology Stack: Built using Python, HTML, JSON data files, and an internal SQLite database for query statistics.
